# Ai là triệu phú - Lập trình Web

Ứng dụng React mô phỏng trò chơi Ai là triệu phú với ngân hàng câu hỏi về HTML, CSS, ES6 và React.

## Chạy ứng dụng

```bash
npm install
npm start
```

## Tính năng

- Tra cứu câu hỏi theo mức độ và từ khóa; xem đáp án ở trang chi tiết.
- Mỗi ván chọn ngẫu nhiên 5 câu cho từng mức độ, xáo trộn đáp án và giữ nguyên chấm điểm.
- Chơi 15 câu, mỗi câu 30 giây, có thang tiền thưởng và các mốc an toàn.
- Dùng quyền trợ giúp 50:50, hỏi khán giả, gọi người thân hoặc dừng cuộc chơi.
- Lưu kết quả vào lịch sử trong trình duyệt.

Chạy kiểm thử bằng `npm test -- --watchAll=false` và tạo bản build bằng `npm run build`.
